# knowledge/ —— 知识库源目录

这个目录是 EvaAI 知识库的**唯一真相**。放在这里的文本文件（`.md` / `.markdown` / `.txt`）
会在服务启动时被切分、嵌入、存进本地的 ChromaDB，模型再用 `knowledge_search` 工具按需检索。

## 怎么用

1. 把你的文档（笔记、约定、手册）放进这个目录，`.md` 最好——标题层级会被保留成每个片段的
   面包屑（`一级标题 > 二级标题`），检索命中时更容易判断"这段在讲什么"。
2. **重启服务**。索引只在启动期建（与配置、技能同一立场：运行期不扫盘）。
3. 改了文件再重启时，启动期会比对指纹，**只对改动过的文件**重建索引；没变就跳过。

## 几条约定

- 源目录即真相：从这里**移走**的文件，索引里也会随之消失（删除也在指纹差异里）。
- 改了**嵌入模型 / 维度 / 切分参数**，整个索引会重建（配方记在库里，启动时自动比对）。
- 详细配置见 `config.yaml` 的 `knowledge:` 节；机制见 `docs/adr/0022`。
- 图片、PDF 暂不支持（留给多模态那片，见 `docs/research/rag-multimodal.md`）。
- 这个目录会被**原样镜像**到沙箱的只读 `/knowledge`，所以模型也能直接 `read_file` 读原文全文。
